# Franchise Conseils Trading (FCT) - Site Web Public (Projet Indépendant)

Ce projet est strictement isolé de l'application interne FCT ERP / CRM.

## Spécifications
- **Emplacement de l'agence :** Carrefour Santa Barbara, Bonamoussadi, Douala, Cameroun
- **Rôle :** Catalogue public de vente de véhicules, vitrine de location avec pré-réservation, formulaire de contact et devis en ligne.
- **Déploiement indépendant :** Hébergement Cloudflare Pages / Vercel / Firebase Hosting dédié.

## Démarrage
```bash
cd website
npm install
npm run dev # Démarre sur le port 3001
npm run build # Build de production isolé
```
